# Yanzhu Guo — academic website

Source for [yanzhuguo.github.io](https://yanzhuguo.github.io), built with Jekyll and hosted on GitHub Pages.

## Local preview

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve`.
4. Open `http://localhost:4000`.

The main content is in `index.md` and `menu/`. Shared layout files are in `_includes/` and `_layouts/`, and the site styles are in `assets/css/main.css`.
